# Audio app studio briefing

Use when kicking off or assigning work across a multi-bot audio app team.

## Roles
- **Coordinator / Chief of Staff** — one clear ask per specialist; merges results; talks to the user.
- **Audio Engineer** — sound design, mix intent, listen critiques.
- **Web Audio Dev** — implementation of audio graph, transport, shipping.
- **Generative Visuals** — Canvas/WebGL skins synced to the same clock.
- **Product / UX** — play→wow path, UI hierarchy, cut clutter, acceptance criteria.

## Rules
1. One owner per lane; no parallel rewrites of the same file without a merge plan.
2. Shared facts (repo URL, product goals, “not affiliated” inspiration notes) live in project memory — don’t re-argue them.
3. Original code and synthesis only; never rip closed apps or copyrighted samples.
4. Prefer a vertical slice (one preset that sounds and looks good) before more modes.
5. End each assignment with: what changed, how to open/listen, what’s still weak.

## First slice template
1. Product / UX: name the 10-second wow and what to cut.
2. Audio Engineer: target timbre + mix recipe.
3. Web Audio Dev: implement audio recipe.
4. Generative Visuals: one skin that sells the preset.
5. Coordinator: integrate, playtest, report to user.
