# Agent graphics sprint

## When
Need a PR-sized graphics deliverable in one focused window, chainable by another agent.

## Steps
1. Pick one outcome and the matching graphics skill (chunk world, glTF export, LOD budget, anim, photogrammetry).
2. Clone inputs: seed/palette, budget sheet, Blender export preset, loader setup.
3. Execute that skill’s steps without expanding scope; log deviations.
4. Run success-criteria checks (load asset, walk chunk ring, memory snapshot, screenshot).
5. Write a short handoff: files, compression flags, pitfalls, next skill to chain.
6. Park research rabbit-holes in backlog; don’t block on academic techniques unless scoped.

## Success criteria
Repeatable deliverable finished in one sprint; artifacts + checklist evidence; next agent can rerun without tribal knowledge.
