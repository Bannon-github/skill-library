# Reverb-freeze atmosphere print: freeze a 100%-wet reverb of a synth phrase, record it to audio, loop it seamlessly with overlapping tail, bus and process as an atmos layer

Goal: Create a background atmosphere layer from any melodic synth part: send it to a 100%-wet, low-cut, high-diffusion/large-size/long-decay reverb with a freeze/hold function, engage freeze while the phrase plays, record the frozen output via a group bus onto a new audio track, then EQ it, add sidechain-style volume ducking and a second ~5–6 s reverb so the loop point is masked, duplicate and overlap the clips with a short end fade for a click-free endless loop, and group the layers into an atmos bus — optionally printing separate closed-filter and open-filter freezes to follow the arrangement.

Source: [Trance Atmosphere Tutorial using Reverb Freeze 🥶](https://www.youtube.com/watch?v=-oFbaWsScJw)

1. Insert a freeze-capable reverb on (or as a send for) the synth phrase: cut the lows, mix 100% wet, raise diffusion, size and decay.
2. Play the phrase and engage freeze at the musically richest moment; the reverb holds indefinitely even when playback stops. Release/turn down to end.
3. Route the synth (with the freezing reverb) to a dedicated group bus, create an audio track whose input is that bus, and record a few bars (~4) of the frozen output. Then remove the temporary reverb and restore the synth's original output routing.
4. On the printed track: EQ low end out and tame highs; add a sidechain-style volume shaper so it pumps with the groove.
5. Add a second reverb on the print (low cut, ~5–6 s decay, larger size, modulation off) so the restart of the loop isn't heard as a jump.
6. Make the clip loop seamlessly: add a small fade at the end, duplicate it onto a second track, and overlap clips so each new clip starts while the previous tail fades.
7. Group both print tracks into an 'atmos' bus; process together (another large reverb with lows cut ~600–700 Hz and reduced feedback/mix, gentle top-end saturation/exciter).
8. If the source filter opens later in the arrangement, print a second freeze with the filter open and use closed/open layers per section.
