# traveler-walkthrough-control-track-filter-wt-animation

Goal: Use dual Control Tracks (sequenced controller lanes) as the heartbeat: up to 16 steps, ping-pong, DAW-synced rates, swing/gate/depth, routing to filter cutoff, wavetable position, or any mod destination.

Source: https://www.youtube.com/watch?v=IU76c2Cygs4

1. Open sequencer/Control Tracks panel. Configure Track A: length ≤16 steps, direction forward or ping-pong, tempo-synced note value.
2. Set Track A destination from the shared mod destination list (same as mod matrix): e.g. filter cutoff or wavetable position. Set depth, gate time, swing.
3. Configure Track B with a complementary destination and optionally different length/rate for evolving polyrhythmic motion.
4. Use utilities: copy A→B, reverse/flip, reset, or randomize steps when exploring — then refine by ear.
5. Optionally pair with arpeggiator: many patterns; can target individual oscillators so one osc arps while another holds a pad; shape arp attacks with mod envelope when per-osc selected.

MCP: `skill://traveler-walkthrough-control-track-filter-wt-animation`
