# Uplifter / downlifter from any saw synth: pitch-bend span, closed LP, accelerating LFO

Goal: Create mix-ready uplifters and downlifters in any wavetable/subtractive synth: hold the root note for ~8 bars, set pitch-bend range to ±6 or ±12 st, close a 12 dB low-pass, map an LFO with an accelerating curve (quarter→eighth→sixteenth) to cutoff and to pitch-bend (50%→100% for up, 50%→0% for down), thicken with unison, then sidechain and add reverb/FX.

Source: [HOW TO MAKE UPLIFTERS & DOWNLIFTERS IN SERUM!!!](https://www.youtube.com/watch?v=t97TU3p7-kE)

1. In the piano roll, draw a single root-note held for about 8 bars so the riser sits in key for a buildup.
2. Set pitch-bend range to 6 or 12 semitones up and down (12 used in the transcript).
3. Enable a low-pass filter (e.g. MG-style 12 dB) and pull cutoff down so highs are removed at the start.
4. Map an LFO to cutoff. Draw an accelerating rate curve in the LFO (start slower ~1/4, then 1/8, then 1/16) and adjust LFO rate to taste.
5. Map the same (or a second) LFO/envelope to pitch-bend position: from 50% toward 100% for an uplifter, or from 50% toward 0% for a downlifter.
6. On a saw source, raise unison (e.g. ~7 voices), reduce detune for a tighter supersaw, and raise stereo blend slightly.
7. Sidechain the riser to the kick (or a rhythmic duck envelope), easing mix if the duck is harsh (~75% wet in the transcript example). Add reverb/FX from the synth FX rack or inserts so it sits in the mix.
