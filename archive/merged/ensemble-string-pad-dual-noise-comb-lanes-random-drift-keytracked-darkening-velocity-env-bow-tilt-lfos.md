# Cinematic ensemble string pad from noise-excited combs: two comb lanes (static vs pink noise, different comb flavours) with fast random pitch drift for a section feel, key-tracked low-pass so low notes stop sounding metallic, a smoothed saw layer and an EQ'd sine/FM low end, a low-boosting resonator, mod-wheel cutoff, velocity that shortens attack and release, a tiny strike pitch envelope and offset triangle 'bow' LFOs on comb tilt

Goal: Build a realistic, wide sustained string pad (not a solo bowed voice) on comb filters. Lane A: static noise with a slow attack and slow release into a comb whose feedback is raised until sharp, low-passed to take the edge off, with a fast random (non-synced) ramp LFO on fine detune so it behaves like many players. Lane B: pink noise (more warmth and body) into a different comb flavour, also detuned. Mix both lanes and control them through one filter with cutoff key-tracked (centre near middle E, about 64 in the middle) so higher keys stay bright and low keys are darker and less metallic; add a little comb distortion. Add body with a smoothed saw (curve filter in string range, doubled for width) and a sine/FM layer EQ'd to low end only. Global FX: subtle mod/diffusion (slow shape), reverb, an EQ resonator mode boosting lows on lane 2, light peak compression. Make it playable: mod wheel → cutoff, velocity → shorter attack and shorter release (never zero), a tiny curved pitch rise on strike applied to both comb pitches, and triangle LFOs at different second-based rates on comb tilt/flavour (not 'structure', which changes pitch). Distinct from today's MPE bowed-string skill: an ensemble pad with drift, dual-lane flavours and velocity/LFO articulation.

Source: [How to Design Cinematic Realistic String Pads - Zebra 3 Sound Design Tutorial](https://www.youtube.com/watch?v=leLAm3OigI0)

1. Lane A: static noise → amp envelope with slow attack and slow release → comb. Raise comb feedback until the tone is sharp and pitched; low-pass the noise to remove edge.
2. Add an LFO set to random ramp, not tempo-synced, routed lightly to fine detune; speed it up until it reads as a group of players, stopping short of vibrato.
3. Global FX: a little mod/diffusion (slow shape), reverb; set a non-resonant 6 dB linear filter as a starting point and increase width.
4. Lane B: duplicate the idea with pink noise into a different comb flavour/complexity, detuned the same way. Mix lanes A and B and route both through one shared filter.
5. Key-track the shared filter cutoff with the centre near middle E (about 64 in the middle). Add a little comb distortion if wanted.
6. Body: add a saw oscillator smoothed with a curve filter in string range (double it for width) and a sine/FM layer EQ'd to keep only low end. Optionally add an EQ resonator boosting lows on lane 2 in the global FX.
7. Playability: mod wheel → filter cutoff; velocity → attack and release so harder strikes get shorter attack and shorter release (keep a minimum above zero); compress only the top peaks.
8. Strike pitch: a short curved envelope adding a tiny pitch rise to both comb pitches (exaggerate to hear, then reduce). Bow motion: triangle LFOs with rates in seconds on comb tilt/flavour, at different rates per lane so they do not move in unison.
