# Make synth layers read as strings or orchestra by obscuring them: two saw-based arpeggiated plucks moving in opposite directions, a fast-open filter envelope and vibrato, a shared pitch-shifting modulated reverb, and level automation plus sidechain so the listener only hears brief glimpses without context

Goal: Imply acoustic strings with simple synthesis plus psychoacoustics. Harmonic content: saw-like spectra (strings and brass are close to a saw series). Layer two arpeggiators playing the same chords: one rising, one reversed so they cross; double the arp step time (half speed); each voice uses a brass-like filter envelope (opens fast, decays: a smoothed pluck), light unison, real vibrato, and a spectral/frequency-mode phaser masked to act above the fundamental so the note pitch stays clean; the second voice has a longer pluck, darker filter and more unison. Arp cycle length depends on chord note count, so voice chords deliberately. Send both to one shared reverb with large size and diffusion, low feedback, a downward pitch shimmer and high modulation depth. Then automate the layer's level by feel so it only comes through at chosen moments, and sidechain it under the drums; a supporting soft chord stack gets a big reverb with a gate so tails don't run on. The brain fills in an orchestra because it never hears the sound's before/after context.

Source: [How To Synth 5: Synthetic Ambient Orchestraish Strings](https://www.youtube.com/watch?v=_cVKvtFm8J0)

1. Program the chords with a fixed note count (e.g. 3 notes) so arp cycles stay predictable; arp cycle length grows with note count.
2. Voice 1: saw-like oscillator, light unison, vibrato on, filter envelope that opens fast then decays (brass-style smoothed pluck), arpeggiator going up at half speed (double the default step time).
3. Add a phaser (or harmonic pitch modulation) masked so it only affects partials above the fundamental, so pitch stays clean while upper harmonics shimmer.
4. Voice 2: same idea with a longer pluck decay, lower filter, a bit more unison, arp direction reversed (starts at the top) so the two layers cross.
5. Send both voices to one shared reverb: large size and diffusion, low feedback, pitch shift down in the feedback, high modulation depth; high-pass and lift the top before the reverb.
6. Automate the layer's level by feel so it only comes through at selected moments, and sidechain it under the drums.
7. Optional support: a soft sustained chord stack with big reverb, gated so tails stop when the chord stops, with a fader dip so it starts large and smooths out.
