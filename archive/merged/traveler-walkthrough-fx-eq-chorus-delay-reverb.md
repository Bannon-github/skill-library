# traveler-walkthrough-fx-eq-chorus-delay-reverb

Goal: Finish a cinematic patch with the Traveler-style FX order: 3-band EQ → multi-type chorus → dual/ping-pong modulated delay → room/hall/space reverb (long space tails).

Source: https://www.youtube.com/watch?v=IU76c2Cygs4

1. Insert 3-band EQ first: sculpt low end, mid presence, and highs so the synth sits in a mix before time FX.
2. Add chorus: choose type 1, type 2, or combined. Keep wet modest for cinematic width without seasick detune.
3. Dual or ping-pong stereo modulated delay: independent L/R times, feedback, stereo spread, feedback filters, and classic delay modulation.
4. Reverb: pick room, hall, or space algorithm (space can reach very long tails). Set size/decay/predelay manually with original settings.
5. Map portable names: KeyTIME-like = tempo-synced modulated delay motion; KeySPACE-like = multi-algo cinematic reverb. Keep FX after synth engine; watch limiter on main out.

MCP: `skill://traveler-walkthrough-fx-eq-chorus-delay-reverb`
