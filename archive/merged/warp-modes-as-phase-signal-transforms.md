# Wavetable warp modes rebuilt as phase-signal transforms (PWM, bend, asym, mirror, sync/window, flip, quantize, remap)

Goal: Rebuild wavetable 'warp modes' portably by splitting an oscillator into a 0-to-1 phase ramp that reads the waveform and then transforming that phase signal before lookup: squeeze (PWM), pinch/skew (bend/asym), mirror, overdrive-and-wrap (sync, optionally windowed), comparator-switched 180-degree rotation (flip), staircase quantize, and a drawn transfer curve (remap), so a Web Audio/AudioWorklet or modular oscillator can chain and modulate several warps at once instead of picking one mode.

Source: [A comprehensive guide to phase and warp modes in Serum, Bitwigs Grid and other synths like it](https://www.youtube.com/watch?v=D4K5g8t3aIc)

1. Model the oscillator as three variables: frequency (set by the played note, how often the cycle repeats), amplitude, and phase (where you are in the cycle and HOW you move from the start position to the end). Warp modes change only the phase motion.
2. Separate phase from waveform: generate a linear phase ramp (sawtooth 0->1 once per cycle at the note frequency) and feed it at 100% into the oscillator's phase input/lookup. A straight ramp must reproduce the original wave exactly. (Bitwig Grid: switch off the oscillator's internal phase section and patch a phase module in; Web Audio: AudioWorklet table read at the computed phase.)
3. PWM: squeeze the phase so it runs through the whole cycle quickly, then holds at the end until the period elapses, then jumps back to 0. Squeezing from one side or from both sides is equivalent once you shift the oscillator start phase. A bipolar version can also stretch/zoom into a small part of the cycle, turning a sine almost into a saw and eventually losing amplitude.
4. Bend (+ / - / +-): apply a pinch curve to the phase. One direction races to the centre, lingers there, then speeds up toward the end; the other direction lingers at the start and end and runs quickly through the middle. Bend +- has its neutral point in the middle of the knob. Asym = a skew curve that moves the turning point to one side.
5. Mirror: run the phase through the whole cycle and then reverse direction back to 0 (a triangle-shaped phase). Raising the amount repeats this faster, almost sync-like. To match a synth whose mirror control moves the two halves closer/further apart, follow the mirror stage with a skew stage.
6. Sync: amplify the phase ramp beyond 1 and wrap anything above 1 back down to 0 so the cycle restarts; more amount = more condensed sub-cycles pushed in from the right. Hard wrapping crackles, especially on a sine; 'window' variants force a zero crossing at the cycle start/end (half window, and full window which extends further toward the ends) to soften it while changing the waveform. A window can only be approximated with envelope-style amplitude shaping if your tool lacks it.
7. Flip: compare the phase ramp to a threshold value (0-1) with a greater/less-than comparator; use the boolean to switch between the original phase and a 180-degree-rotated copy (split/rotate, then merge/select). The wave inverts exactly where the ramp crosses the threshold, and the knob covers two cycles of this. A plain phase-reverse module is NOT the same result.
8. Quantize: run the phase through a quantizer so only discrete steps are allowed (a staircase), giving a bit-crusher-like distortion of the wave.
9. Remap: draw an arbitrary transfer curve mapping phase-in to phase-out (e.g. stay at the beginning, then catch up exponentially) with the warp amount as the depth; Remap 2/3/4 apply the shaping repeatedly/repeat the waveform more often. LFO-style shapes can be used as curves.
10. Treat FM as related (it also moves phase, via another oscillator) but separate from warping; keep it in its own stage.
11. Chain several phase transforms in series (e.g. PWM-style squeeze then pinch, or mirror then skew) and assign each amount to LFOs, envelopes or macros for evolving cinematic motion.
