# Classic swept analog pad/lead: two detuned oscillators into a state-variable (SEM-style) filter driven by a triangle 'fin' filter envelope that rises then falls, modest resonance, mono mode with 8-voice stereo unison, light compression and tape echo, and an optional second oscillator pair through a different filter type swept the same way

Goal: Recreate the classic 70s/80s filter-sweep sound from scratch. Use a low register and two oscillators slightly detuned for a phasing movement. Put them through a state-variable (SEM/Oberheim-type) lowpass and give the filter envelope a triangle 'fin' shape: a slow attack up and a slow decay back down with low sustain, so each note sweeps open and closes again; set envelope intensity, then add a little resonance (not too much). Switch to mono mode with full stereo unison (all 8 voices) and some detune for size. Finish with light compression and tape echo (no chorus needed). Optional: route oscillators 3–4 to a second, different filter type with its own fin envelope and detune, then blend both layers. More specific than our generic pad swell skills: up-and-down fin envelope on the filter plus mono unison stack.

Source: [Why This Classic Filter Sweep Still Sounds So Good](https://www.youtube.com/watch?v=xil_HpL1izg)

1. Init a patch. Choose a state-variable (SEM-style) lowpass, and if the synth offers vintage amp/envelope models, use them. Play in a low register with two oscillators slightly detuned.
2. Shape the filter envelope as a triangle 'fin': slow rise to the peak, slow fall back down, low sustain. Set envelope intensity so the cutoff travels a wide range.
3. Add a little resonance, just enough to make the sweep sing without whistling.
4. Switch to mono mode with full stereo unison (8 voices) and add unison detune.
5. Add light compression and a tape echo. Skip chorus, because unison already gives width.
6. Optional: enable a second filter of a different type, send oscillators 3–4 to it, give it its own fin envelope and some detune, then blend both layers (pull back if it gets too dense).
