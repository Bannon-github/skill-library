# traveler-walkthrough-super-unison-wide-lead

Goal: Build a gigantic wide lead/pad layer using a multi-voice stereo unison oscillator (Traveler Osc2-style stack up to ~7 voices) with waveform morph and stereo spread.

Source: https://www.youtube.com/watch?v=IU76c2Cygs4

1. Assign Oscillator 2 role as the Super/unison stack: continuous waveform from saw through sine to thin pulse.
2. Enable stereo voice stack (up to ~7 voices). Increase detune and stereo spread until the stack alone sounds gigantic.
3. Optionally add Osc1 as FM/sync carrier support (sync Osc2; FM from Osc2/3 linear or exponential, variable depth) for bite.
4. Mixer: set Osc2 level primary; pan can be modulated later. Mild drive into filter if available.
5. Route through stereo ladder-style LPF (12–24 dB). Keep cutoff high enough to preserve width; use modest resonance.
6. Amp envelope: medium attack for pads or fast attack for leads; sustain mid-high; release 0.5–2s. Enable pan-spread / voice stereo distribution if available.
