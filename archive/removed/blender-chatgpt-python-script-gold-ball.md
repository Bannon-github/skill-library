# blender chatgpt python script create gold ball

Goal: Use ChatGPT to generate a Blender Python script, paste it in the Scripting workspace, and run it to create a material-previewable object.

Source: https://www.youtube.com/watch?v=x60zHw_z4NM

1. Install/launch Blender from blender.org; dismiss splash.
2. Open chat.openai.com; prompt e.g. write a Blender script that creates a gold ball (include the word script).
3. Copy the code block from ChatGPT.
4. In Blender, select default cube, press X and confirm delete for a blank start.
5. Open Scripting workspace tab → New → paste (Ctrl/Cmd+V).
6. Click Run; switch back to Layout; enable Material Preview shading to see material color.
7. If the script errors, copy the error into ChatGPT and retry with the fixed script.

MCP: `skill://blender-chatgpt-python-script-gold-ball`
