# blender metric millimeters setup for 3d print

Goal: Configure Blender scene units and grid to millimeters for dimension-accurate hard-surface / 3D-print modeling.

Source: https://www.youtube.com/watch?v=8_0RptMbhe0

1. Open Scene Properties; set Unit System to Metric.
2. Set Unit Scale to 0.001 and Length to Millimeters.
3. Open Viewport Overlays; set grid Scale to 0.001 so the grid matches mm.
4. Select object; press N for Sidebar; confirm Location/Rotation/Scale/Dimensions read in mm.
5. Reset object location to 0,0,0 if recentering at origin.
