# blender donut tutorial navigation add mesh shade smooth

Goal: Start the Blender Guru beginner path: install/open Blender, navigate, delete cube, add torus/cylinder, shade smooth, learn G/R/S.

Source: https://www.youtube.com/watch?v=z-Xl9tGqH14

1. Download Blender 5.x (or current) from blender.org; install or use portable zip; open and click off splash.
2. Orbit MMB-drag; Shift+MMB pan; scroll zoom; use axis gizmo clicks if upside-down.
3. Optional: Preferences → Interface Resolution Scale for readable UI; Input Emulate 3 Button Mouse if no MMB.
4. Delete default cube (X → Delete).
5. Shift+A → Mesh add (torus for donut path / cylinder for mug path); adjust Add last-operation settings before clicking away.
6. Right-click object → Shade Smooth when appropriate.
7. Practice G/R/S; Tab Edit mode to edit geometry; return to Object mode to select other objects.
