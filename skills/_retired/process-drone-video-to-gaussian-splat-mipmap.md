# process-drone-video-to-gaussian-splat-mipmap

**Goal:** Build a splat from that video in Mip-Map.

**Source:** 3D Gaussian Splatting | How to Create 3D Gaussian Splatting From Drone Video Beginner Guide
**URL:** https://www.youtube.com/watch?v=mQ4EHUpXj9Q

## Steps

1. Import the video into Mip-Map.
2. Extract frames using subtitle GPS when present.
3. Run Gaussian splat reconstruction.
4. Inspect and export the 3D splat.
