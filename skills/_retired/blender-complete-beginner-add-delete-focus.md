# blender complete beginner add delete and focus

Goal: After basic navigation, delete/add mesh objects, focus selection, use F3 search, and save the .blend.

Source: https://www.youtube.com/watch?v=uOmYInaX-wE

1. Dismiss splash; practice orbit/pan/zoom; use View Selected (numpad period) if lost.
2. Learn F3 operator search (context-sensitive to Object mode vs elsewhere).
3. File → Save As to create your .blend early.
4. Select default cube; X → Delete (Enter) to remove it.
5. Shift+A → Mesh → add primitives (cube, monkey, etc.); practice add/delete.
6. Numpad 0 (or camera icon) to preview camera framing used for renders.
