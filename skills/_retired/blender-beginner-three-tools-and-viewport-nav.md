# blender beginner three tools and viewport nav

Goal: Learn Move/Rotate/Scale tools and MMB viewport navigation (with trackpad alternatives) as absolute beginner foundations.

Source: https://www.youtube.com/watch?v=98qKfdJRzr0

1. Edit → Preferences → set Resolution Scale (e.g. 1.25) so UI is readable.
2. Activate Move tool; drag RGB handles to move the cube.
3. Activate Rotate tool; drag handles to rotate.
4. Activate Scale tool; drag the white uniform handle to scale on all axes.
5. Navigate: MMB orbit, Shift+MMB pan, scroll zoom (use Emulate 3 Button Mouse / trackpad alternatives if needed).
