# blender install preferences and viewport basics

Goal: Install Blender, set useful preferences, and learn viewport nav plus G/R/S and Object/Edit mode.

Source: https://www.youtube.com/watch?v=Ci3Has4L5W4

1. Download Blender from blender.org and install for your OS; open and click outside splash to dismiss.
2. Edit → Preferences → Interface: adjust Resolution Scale if UI is tiny/huge.
3. Preferences → System: enable CUDA/GPU Cycles device if available; raise Undo Steps (e.g. 100); Save Preferences.
4. Viewport: MMB orbit, Shift+MMB pan, scroll zoom; optional gizmo orbit/zoom/pan; numpad/gizmo axis views.
5. Learn Move/Rotate/Scale tools and hotkeys G, R, S; axis-constrain with X/Y/Z; Tab for Edit mode.
