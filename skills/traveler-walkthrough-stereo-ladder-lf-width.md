# traveler-walkthrough-stereo-ladder-lf-width

Goal: Shape a cinematic tone with stereo ladder/NJM-style filters, left/right cutoff offset or per-key spread, linked high-pass for band-pass effects, and low-frequency width so bass stays centered while highs move.

Source: https://www.youtube.com/watch?v=IU76c2Cygs4

1. Choose ladder-style LPF slope from gentle 6 dB to steep 24 dB (four ladder variants) OR NJM 2069-style model for DW/Poly-era character.
2. Enable stereo filter path. Offset left vs right cutoff, or use automatic per-key spread, for subtle stereo timbre differences (good automation target).
3. Add dedicated high-pass; optionally link HP to primary cutoff for band-pass style sweeps. Set keyboard tracking and envelope amounts for both LP and HP.
4. Output section: set pan-spread so successive voices fan across the stereo field; optional random voice position.
5. Engage low-frequency width / LF-width: narrow pan of content below ~middle C so bass stays mono-centered while upper spectrum keeps stereo motion.
6. Optional vintage/voice-offset knob for slight per-voice drift of tune, mixer, filter, envelopes — keep near 0 for clean cinematic pads.
