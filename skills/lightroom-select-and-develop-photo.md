# lightroom-select-and-develop-photo

**Goal:** Edit one photo end-to-end in Lightroom.

**Source:** EDIT PHOTOS Like a Pro // Complete LIGHTROOM Tutorial
**URL:** https://www.youtube.com/watch?v=owStZxm9DIA

## Steps

1. In Library, pick a strong base photo.
2. Open Develop on the unedited version.
3. Set global exposure, contrast, and white balance for the light.
4. Add local adjustments to separate subject from background.
5. Refine color/crop; export final file.
