# Reverb for pads: pick type by texture, then set up 100%-wet EQ'd send returns

Goal: Choose and route cinematic pad/synth reverb: decide if reverb is needed; pick type by texture not just length (hall lush 2–3s+ with mud risk, chamber thickening with less space, room/ambience intimate ~0.3–1s, plate bright attack→darker decay, spring metallic/boingy); keep 2–3 go-to returns (room ~1s, long plate ~6s, bright spring ~4s) at 100% wet on sends; high-pass returns ~200 Hz+; use pre-delay for clarity, layer short ambience under longer hall/plate, prefer shorter spaces in busy mixes, and pull send back on longer decays.

Sources (merged 2026-10-03):
- https://www.youtube.com/watch?v=_fHK9g9nwMM (from `reverb-types-hall-chamber-room-plate-spring`)
- https://www.youtube.com/watch?v=VnCpRTsg_G8 (from `reverb-send-wet100-eq-room-plate-spring`)

1. Decide intentionally whether the source needs reverb (do not add by default). Match genre references.
2. Recall controls: pre-delay separates dry from reverb onset (clarity); early reflections cue size/material; tail/late reflections = sustain; decay = fade. Think texture/tonality more than length alone.
3. Hall: large auditorium character, often ~2–3s+ (longer for cinematic/atmosphere); lush/deep, thickens and pushes source back—high mud risk. Natural for piano/strings/orchestra.
4. Chamber: studio reflective-room character—lush thickening with less mix real-estate than hall; very versatile (pads, strings, vocals). Room/ambience: smaller/intimate; ambiences often ~0.3–1s, ER-heavy—liveliness without takeover.
5. Plate: mechanical metal-plate density; bright quick attack then darker decay—great sustain/sheen. Spring: metallic/boingy modulation in decay—character FX more than lush pad default.
6. Build 2–3 saved returns: (1) room ~1s+ decay for basic space; (2) long ambient plate (transcript example ~6.2s); (3) spring or other bright flavor (~4s). Save in template.
7. Use sends: set reverb mix to 100% wet on the return. Control amount only via send level so dry stays constant and wet can be EQ'd independently.
8. EQ the reverb return after the algo: high-pass everything below ~200 Hz (or higher) so reverb does not invent mud. Optional cuts for metallic harshness (e.g. spring).
9. Practice: pick type in solo for texture, set level in full mix. Layer short ambience under longer hall/plate. Busy mixes → shorter rooms/plates; sparse/ballad → longer halls/plates. Optional high-cut on reverb darkens and pushes wet further back.
10. Add too much send, then back off to a musical amount. Longer decays usually need less send; shorter rooms can take more. Share one long plate across lead vs backgrounds with different send depths.
