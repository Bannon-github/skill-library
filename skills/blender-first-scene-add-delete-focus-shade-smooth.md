# Blender first scene: delete/add primitives, focus, F3 search, shade smooth, save

Goal: Start a first Blender scene (Blender Guru donut/mug path or any beginner path): open Blender, navigate and recover with View Selected, use F3 operator search, Save As early, delete the default cube, add mesh primitives with the Add last-operation panel, Shade Smooth, practice G/R/S and Tab Object/Edit mode, and check camera framing with Numpad 0.

Sources (merged 2026-10-03):
- https://www.youtube.com/watch?v=z-Xl9tGqH14 (from `blender-donut-tutorial-nav-add-shade-smooth`)
- https://www.youtube.com/watch?v=uOmYInaX-wE (from `blender-complete-beginner-add-delete-focus`)

1. Download Blender 5.x (or current) from blender.org; install or use portable zip; open and click off splash. Dismiss the splash.
2. Orbit MMB-drag; Shift+MMB pan; scroll zoom; use axis gizmo clicks if upside-down. Use View Selected (numpad period) if lost.
3. Optional: Preferences → Interface Resolution Scale for readable UI; Input Emulate 3 Button Mouse if no MMB.
4. Learn F3 operator search (context-sensitive to Object mode vs elsewhere).
5. File → Save As to create your .blend early.
6. Select the default cube; X → Delete (Enter) to remove it.
7. Shift+A → Mesh → add primitives (cube, monkey, torus for the donut path / cylinder for the mug path); adjust Add last-operation settings before clicking away; practice add/delete.
8. Right-click object → Shade Smooth when appropriate.
9. Practice G/R/S; Tab Edit mode to edit geometry; return to Object mode to select other objects.
10. Numpad 0 (or camera icon) to preview camera framing used for renders.
