# keysol-venus-fifths-pulsar-wt-impact

Goal: Craft a throbbing aggressive impact/pulse by tuning a second oscillator up a fifth (+7 semitones), adding duo/detune/scatter width, and a wavetable layer for dimension beyond plain VA.

Source: https://www.youtube.com/watch?v=jLGz5wq2CRE

1. Build throbbing aggressive core on Osc1 (pulse/saw). Set Osc2 +7 semitones for fifths power; balance for deep power vs mid punch vs brighter transient emphasis.
2. Enable duo/unison, detune, and stereo scatter/spread for width.
3. Add wavetable oscillator not as a full replacement but as dimensional spice; animate WT position for movement.
4. Play velocity-reactive syncopated rhythms into a bouncing delay so the part stays alive across long phrases.
