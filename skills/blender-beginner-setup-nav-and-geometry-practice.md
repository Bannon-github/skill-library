# blender beginner setup navigation and geometry practice

Goal: Start Blender the right way: Layout workspace focus, three-button mouse nav, G/S/R, Edit mode verts/edges/faces, then freeform practice.

Source: https://www.youtube.com/watch?v=TG_vamse41c

1. Write a short learning map: end goal plus key concepts/procedures to learn (skip unrelated tutorials).
2. Open Blender; select Layout workspace; mentally ignore top menus, Outliner, Properties, Timeline—focus on 3D Viewport and default cube.
3. Use a three-button mouse: scroll zoom; MMB drag orbit; Shift+MMB pan. Practice small incremental orbits from screen center.
4. Object mode: G grab/move, S scale, R rotate the cube; click to confirm.
5. Tab into Edit mode. Selection modes: 1 vertex, 2 edge, 3 face. G/R/S components; Shift-click or box-select (wireframe for through-select).
6. Tab to Object mode; Shift+A → Mesh to add primitives at the 3D cursor; G to place; edit in Edit mode.
7. Delete extras in Object mode with Shift+X, Enter. Build rough recognizable shapes without tutorials to cement fundamentals.
