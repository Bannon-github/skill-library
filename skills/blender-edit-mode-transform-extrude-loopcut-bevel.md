# blender edit mode transform extrude loop cut bevel

Goal: Switch Object/Edit mode and use core mesh edit hotkeys (G/S/R/E, Ctrl+R, Ctrl+B).

Source: https://www.youtube.com/watch?v=peSv5IT5Ve4

1. Select the mesh; use Object mode for whole-object transforms (G grab/move).
2. Enter Edit mode (Tab) to edit vertices, edges, or faces; switch selection modes for verts/edges/faces.
3. Press A to select all; S to scale selection; R to rotate (optionally R then Y/X/Z to axis-lock).
4. Select a face and press E to extrude; axis-lock with E then Z (or X/Y) when needed.
5. Press Ctrl+R for a loop cut; scroll wheel for multiple cuts; click to confirm.
6. Alt-select an edge loop; Ctrl+B to bevel; scroll wheel to add bevel segments.
7. Optional: right-click Shade Smooth / Auto Smooth for softer shading without micro-bevels.
