# Granular slicer workflow: map keys to grain position instead of pitch (key→transpose 0, key→position up) with glide between slices, lock grain size to tempo in ms, per-parameter variation and L/R pitch spread for an icy cloud, an envelope that morphs grain shape and size per note, scan + per-ear LFOs for glitch, and a square-LFO auto-recapture of live drums every two bars

Goal: Play any long recording (vocal, sound-design session, loop, live drums) as an ethereal slice instrument. Use three grain modes for different jobs: classic (overlapping, sustained), loop (non-overlapping, with reverse chance) and cloud (stacked grains, density). Set key→transpose to 0 and key→filter to 0, then turn key→position up so each key plays a different part of the file; enable mono + glide to glide between slices; smaller grains change position faster. Tune the pad version by checking the sample's pitch with a tuner. In cloud mode raise variation on grain size, small transposition (chorus) and volume, and add spread for different L/R pitch. Lock grain size to tempo by converting a note length to ms (a quarter note read as 408 ms). Remember transposition changes grain duration: 76.1 ms at 0 st becomes half at +12 st. Use the modulation envelope negatively on grain shape and size for plucky transients (decay ~1 s). Use scan (e.g. 0.25×) with LFOs (different per ear) on grain size and position for glitch, and auto-capture live drum input every two bars with a square, skewed LFO for generative texture. Delta vs our granular skills: key-to-position slicing with glide, tempo-ms grain lock and periodic self-recapture.

Source: [granulate EVERYTHING](https://www.youtube.com/watch?v=ZVLM1XMT6Z0)

1. Load a recording into the granular sampler and learn the three modes: classic (overlapping, sustained), loop (non-overlapping; set reverse chance) and cloud (stacked grains, density control).
2. For a pad: check the sample's pitch with a tuner and transpose so C3 plays C. In cloud mode turn up variation, with orange per-parameter amounts on grain size, a little transposition (chorus) and volume; reduce position variation if too scattered. Add spread for different L/R pitch.
3. For slicing: set key→transpose and key→filter to 0, set key→position up. Each key now plays a different region. Enable mono + glide to glide between slices; reduce grain size so position changes faster. Use it for vocal-chop patterns and transpose to the song key.
4. Tempo-lock grain size: measure a note length in ms (e.g. select a quarter note and read its duration, 408 ms in the example) and type it in. Remember +12 st transposition halves grain duration (76.1 → ~38 ms).
5. Transient shaping: route the modulation envelope negatively to grain shape (pointy → regular) and to grain size (small → normal), decay ~1 s, in classic mode.
6. Glitch motion: set scan to ~0.25× and modulate grain size and position with an LFO that differs per ear. Record knob automation while playing.
7. Generative recapture: feed live drum clips (random follow actions, legato on) into the granulator's capture input; drive capture with a square, skewed LFO every two bars; hold one note and scan slowly; map an LFO to grain size/shape. Resample the result to layer under the beat.
