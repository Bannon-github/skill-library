# blender game dev learning path advice

Goal: Follow a game-dev-oriented Blender learning order: basics → low-poly assets → early engine export → optional sculpt/bake.

Source: https://www.youtube.com/watch?v=smluafHtCeY

1. Optionally do a short beginner control/UI tutorial (donut parts early only if used).
2. Prioritize low-poly game-asset fundamentals where polygon count matters over dense non-game scenes.
3. Export a simple mesh to your game engine as early as possible; fix export issues before detailing.
4. Practice easy low-poly models on your own; then study rigging; later sculpting and baking high-to-low when needed.
5. Finish a small personal/game-jam asset project end-to-end for retention.
