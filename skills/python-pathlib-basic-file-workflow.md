# python-pathlib-basic-file-workflow

**Goal:** Common file tasks with pathlib.

**Source:** Python Tutorial: Pathlib - The Modern Way to Handle File Paths
**URL:** https://www.youtube.com/watch?v=yxa-DJuuTBI

## Steps

1. from pathlib import Path
2. Build paths with Path.cwd()/Path.home() and the / operator.
3. Use exists(), mkdir(parents=True, exist_ok=True).
4. read_text/write_text; iterdir/glob for listing.
5. Prefer Path objects over string concatenation.
