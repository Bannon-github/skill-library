# Distorted-delay return: drive → ping-pong delay on a 100%-wet send, both band-limited to high mids, return pre-attenuated, played by riding the send

Goal: Add crunchy, wide echo throws to a lead/pluck without mud or volume spikes: on a send/return insert drive then ping-pong delay, band-limit both to the high mids so lows aren't delayed, feedback ~56%, both 100% wet; dial drive/tone at maximum send, then pull the return down ~−6 dB as a safety ceiling, and perform/draw send-level automation so only chosen notes throw distorted echoes — the delta vs our ping-pong delay skill is drive-before-delay on a return and send-throw performance.

Source: [Ableton Sound Design Tutorial - Distorted Delays](https://www.youtube.com/watch?v=4fpZFYG83fw)

1. Create a spare return. Insert overdrive then delay (ping-pong).
2. Set the overdrive's pre-filter to the high mids only, and do the same on the delay's filter so only that band is delayed.
3. Delay: ping-pong for width, feedback ~56%; both devices 100% wet so only effect signal returns.
4. Turn the send to maximum and dial drive and tone to the desired timbre.
5. Pull the return fader down (~−6 dB start) so maxed sends never produce super-loud output.
6. Perform: jam the send knob live to feel where echoes should happen, then tidy or draw send automation per note (some full, some partial).
7. Check in context with the full track and adjust.
