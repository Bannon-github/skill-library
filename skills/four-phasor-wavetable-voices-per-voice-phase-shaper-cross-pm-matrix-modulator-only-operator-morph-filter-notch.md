# Four-voice phasor-driven synth: each voice is a wavetable read by its own phasor (pitch = phasor rate) with a phase-shaper for phase distortion (curve, S-curve, split, triangle, fold), all four outputs fed back through a 4x4 matrix into each other's phase inputs for cross phase modulation, panned and mixed, then a lowpass→bandpass→highpass→notch morph filter and drive

Goal: Build a playable hybrid voice that combines three ways of shaping tone: wavetable morphing, phase distortion and cross phase modulation. Drive each wavetable oscillator with a rising unipolar saw phasor (the phasor's rate sets the pitch; with no phasor there is no sound). Put a phase shaper between phasor and table: bending the phasor (curve, S-curve, split, triangle or fold modes) changes how the table is read, so a sine becomes brighter shapes without a filter. Make four such voices, mix them in stereo with per-voice pan (and pan modulation), and route all four post-shaping outputs back through a 4x4 matrix mixer into each voice's phase-modulation input so any voice can modulate any other, or itself (feedback). Use octave relationships between carrier and modulator (modulator an octave or two below, slightly detuned) and keep one voice muted as a modulator only. Finish with a filter that morphs lowpass → bandpass → highpass → notch, LFOs on cutoff and morph at different rates, drive, and reverb last. Delta beyond our single-oscillator phase-distortion and warp-mode skills: the four-voice cross-PM matrix with per-voice PD and a modulator-only voice.

Source: [Phase Distortion / Phase Modulation Synth in VCV Rack](https://www.youtube.com/watch?v=JC-UA2C-sZU)

1. Drive a wavetable oscillator with a rising unipolar saw phasor. Confirm on a scope that there is no output without the phasor, and that the phasor's rate sets the pitch. Start on a sine frame and morph between a few basic frames.
2. Insert a phase shaper between phasor and table. Raise the shape amount in curve mode, then try S-curve, split, triangle and fold modes, watching the bent phasor on the scope.
3. Duplicate the voice to four voices. Mix them in a stereo mixer with per-voice pan. For unipolar pan modulation, set pan fully left and the attenuverter fully right so the modulation sweeps across the field.
4. Feed the four post-shaping voice outputs into a 4x4 matrix mixer and send its four outputs to the voices' phase-modulation inputs (inputs fully open). Example: listen to voice 1 only, and use voice 2 an octave down (slightly detuned) to modulate voice 1's phase; then put voice 3 two octaves down to modulate voice 2.
5. Add phase distortion and a different shape on a modulator voice (for example triangle mode on voice 2, folding on voice 4) and modulate its shape and PD amount with LFOs. Keep voice 4 muted in the mix so it works only as a modulator.
6. Modulate PD amount with a slow LFO through an attenuverter; optionally modulate the matrix amounts too (for example voice 1 → voice 2) so cross-PM depth moves over time.
7. Route the mix through a multimode filter that morphs lowpass → bandpass → highpass → notch. Close the cutoff, then modulate cutoff and morph with two LFOs at different rates. Add drive, choose a plucky or long amp envelope, and add reverb last.
